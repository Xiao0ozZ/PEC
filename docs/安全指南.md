# 安全说明

## 支持范围

当前维护分支为 `main`。安全修复优先进入当前版本，不承诺维护旧构建快照。

## 报告问题

请不要在公开 Issue 中提交真实项目资料、目录结构、账号、令牌或客户信息。请通过仓库维护者公开资料中提供的私下联系方式报告安全问题，并包含：

- 受影响版本或提交；
- 可复现步骤与最小示例；
- 实际影响；
- 建议修复或缓解方式（如有）。

## 本地资料边界

- `projects/` 与 `project-mounts.local.json` 只用于本机资料，已被 Git 忽略。
- 外部项目挂载只保存到本地配置，静态评审清单不会写入绝对路径。
- 开发服务提供的写操作应只在受信任的本机或内网使用，不应直接暴露到公网。
- 生产构建是只读快照，不提供项目创建、导入或配置写入。
