# 2026-08-04 合作通路租車券测试Bug

## BUG-20260804-CT-UI-LIST-001（P0）

名单批次 `batchId=16` 已存在相关证件号码时，再次导入4行名单仍显示“匯入成功”，提交后继续提示“追加成功”，租車券总数由9张增加至13张。同一批次证件号码唯一性校验未生效，造成重复发券。

## BUG-20260804-CT-UI-ENTERPRISE-001（P1）

企业端左侧菜单已显示“合作通路租車劵”，点击后进入404页面，企业端列表、详情和导出无法继续测试。

## BUG-20260804-CT-UI-DETAIL-001（P1）

营运端数量批次与名单批次详情中的“适用据点类型”和“适用据点”均为空，无法核对批次实际可用范围。

## BUG-20260804-CT-UI-INVENTORY-001（P1）

名单批次 `batchId=16` 已有13张已发放租車券，但车辆库存提醒仍显示“待汇入名单、当前批次0张、适用据点可用0台”，统计未按现有租車券刷新。

## BUG-20260804-CT-UI-EXPORT-001（P1）

营运端批次详情点击“匯出”后，没有触发文件下载，也没有成功或失败提示，无法取得Excel文件。

## BUG-20260804-CT-UI-EDIT-001（P2）

数量生成批次进入编辑弹窗后，数量输入框已禁用，但“减少数值”和“增加数值”按钮仍可点击，界面仍会误导用户可修改已锁定数量。
