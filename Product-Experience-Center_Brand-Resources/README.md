# Product Experience Center 品牌资源包

适用于 GitHub 项目：Product-Experience-Center（产品功能体验中心）。

## 核心概念
图形由多层“页面 / 项目卡片”汇聚组成，表达项目包、原型页面、文档与评审内容在同一工作台中被组织和体验。前景蓝色页面保留两个圆点与两条内容线，强化“可运行产品页面”的识别。

## 标准色
- Brand Blue: #1677FF
- Deep Blue: #0958D9
- Sky Blue: #91CAFF
- Pale Blue: #EAF4FF
- Ink: #12213A

## 目录
- `01_logo/`：中文主标、英文主标、深/浅背景版本（SVG + PNG）
- `02_icon/`：纯图形标、侧栏折叠小图标、多尺寸 PNG
- `03_favicon/`：浏览器标签资源，含 favicon.ico
- `04_app-icon/`：带蓝色圆角底的 App / 桌面 Icon，最大 1024px
- `05_github/`：GitHub 项目头像
- `06_preview/`：资源预览图

## 建议使用
- 管理后台展开侧栏：`01_logo/svg/logo-horizontal-cn.svg`
- 管理后台折叠侧栏：`02_icon/svg/icon-sidebar.svg`
- 浏览器标签：`03_favicon/favicon.ico` 或 `favicon.svg`
- GitHub 头像：`05_github/github-avatar-512.png`
- PWA / 桌面应用：`04_app-icon/app-icon-512.png` / `app-icon-1024.png`

所有 PNG 均为可直接使用资源；图形 SVG 为矢量格式，可无损缩放。Logo 中的文字使用常见系统字体栈，不随包附带任何字体文件。
