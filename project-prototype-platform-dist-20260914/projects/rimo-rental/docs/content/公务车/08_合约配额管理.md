## 1. 页面范围

原型页面：`02_原型和PRD/原型/企业端/contract_quotas.html`

页面用途：查看公务车合约、配额、分公司分配和车辆绑定情况。

## 2. 页面口径

1. 页面名称使用“合约配额管理”。
2. 企业端不创建正式合约，正式合约由营运端或平台侧管理。
3. 企业端用于查看合约、分配配额、绑定车辆和确认额度使用；总公司管理员可在本企业合约之间转移车辆。

## 3. 数据范围

1. 企业总管理员可查看企业全部合约与配额。
2. 企业总管理员可向分公司分配合约配额。
3. 分公司管理员可查看本分公司可用合约、配额和绑定车辆。
4. 分公司管理员不可调整其他分公司配额。

## 4. 顶部卡片

| 指标 | 说明 |
| --- | --- |
| 合约数 | 当前查看范围内有效公务车合约数量 |
| 总配额 | 合约下可绑定车辆总数 |
| 已分配配额 | 已分配给分公司的配额数量 |
| 未分配配额 | 总配额 - 已分配配额 |
| 已绑定车辆 | 已占用配额的车辆数量 |

卡片支持点击筛选，再次点击取消筛选。

## 5. 列表字段

| 字段 | 说明 |
| --- | --- |
| 合约编号 | 合约唯一编号 |
| 合约名称 | 合约名称 |
| 合约类型 | 新增、续费等 |
| 计费周期 | 月、季、年等 |
| 有效期 | 合约起止日期 |
| 配额使用 | 已用 / 总配额 |
| 状态 | 有效、待续费、已到期、已终止 |
| 操作 | 详情、分配配额、绑定车辆、调整配额 |

## 6. 配额分配规则

1. 只有企业总管理员可以分配集团合约配额。
2. 分配数量不得超过总配额减已分配配额、再减待执行转入任务预留新增配额后的可用数。
3. 调减配额时，调减后的配额不得小于该分公司已绑定车辆数量与任务预留既有空闲配额之和。
4. 合约已到期、已终止或处于不可用状态时，不允许新增分配。
5. 分公司绑定车辆数量不得超过该分公司可用配额。

## 7. 验收标准

1. 总管理员可以查看全部合约配额并分配给分公司。
2. 分公司管理员只能查看本分公司合约配额。
3. 配额不足时，不允许继续绑定新车辆。
4. 合约到期后不再开放新车辆绑定和新预约。
5. 转移后车辆 ID 不变，来源已绑定数减少、目标已绑定数增加；列表、分公司明细和车辆弹窗使用同一份绑定数据。
6. 目标分公司已分配10台、已绑定8辆时，仅能复用2台；转入3辆应新增1台配额。重复分配记录按分公司 ID 汇总，不覆盖原分配。
7. 任务取消释放预留，失败不发生部分转移；修改校验失败或取消确认不改变旧任务。
8. 分公司管理员不能创建、修改、取消任务；接口拒绝跨企业合约及越权操作。

## 8. 车辆转移

### 8.1 入口与范围

总公司视角提供“合约转移任务”，合约操作列保留“转移至其他合约”。来源合约为生效中、即将到期或已过期且仍有绑定车辆；即使暂时没有目标合约也保留来源入口。目标必须属于登录企业，与来源不同，并在执行时有效；付款中、已终止、已作废合约不可接收车辆。企业身份取自登录上下文，不接受客户端自行指定企业范围。

弹窗保留来源、目标配额信息及按分公司选择车辆的布局。用户只选车辆，不填写转移配额。选车弹窗的搜索、勾选和取消不得丢失其他搜索结果中已选车辆。

### 8.2 执行规则

- 来源合约及来源分公司的分配配额保持不变，来源合约不自动终止。
- 目标同分公司可复用配额 = 已分配配额 − 当前已绑定车辆数 − 其他待执行任务预留的既有空闲配额。
- 本次新增配额 = 各分公司 max(0，本次选中车辆数 − 该分公司可复用配额) 之和。新增配额不得超过目标待分配可用数。
- 只改变车辆的合约绑定，车辆 ID、资产归属分公司、据点、状态及历史订单保持不变。目标对应分公司不存在分配记录时新增，存在时仅补足差额。
- 确认提交需二次确认、提交防重，并在确认后重新校验状态、车辆绑定、容量及权限；不能仅依赖按钮禁用。

### 8.3 时间与任务

支持立即转移及来源合约到期时转移。立即转移要求目标已生效；到期执行时间取来源结束次日00:00和目标生效时间中的较晚值，必须晚于当前时间且早于目标到期时间。存在生效空窗时，车辆按来源到期规则停用，后续换约不自动恢复上架。

任务状态只有待执行、已完成、执行失败、已取消，不设置执行中状态。列表支持合约搜索、状态筛选、每页5条分页。待执行可编辑或取消，失败可处理重提或取消，完成及取消只读；历史使用提交时快照。立即转移成功直接生成已完成任务，不显示待执行标签。

待执行任务在来源、目标合约显示“有转出任务”“有转入任务”；失败显示“转移失败”并保留至处理或取消。标签可打开对应合约的任务列表。

### 8.4 预留与一致性

- 同一来源仅允许一条待执行任务。保存任务立即预留目标对应分公司的既有空闲配额及不足部分的新增配额，其他任务、配额分配和车辆绑定不能占用。
- 任务车辆在执行或取消前不可解绑、改绑或调拨分公司。允许继续执行已有用车订单。
- 编辑校验时排除本任务原预留，成功后原子替换；不能先释放再校验。取消释放预留，不修改来源配额或车辆。
- 后端统一维护营运端和企业端的任务、预留和车辆绑定；两端不能各自维护互不相知的预留。定时执行不依赖页面打开。
- 执行在同一数据库事务中完成目标配额补足、车辆改绑、预留释放及任务完成，使用任务版本号、幂等键和锁防止重复执行。任一步失败整体回滚，任务失败并释放预留，记录原因供管理员处理。
- HTML 原型仅演示当前页面内存中的数据变化与定时触发，不跨页面共享、不持久化，不代表后端定时任务已经实现。
