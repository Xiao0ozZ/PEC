## 液态玻璃（Liquid Glass）参考站点清单（2026-09-11 调研）

> 用于顶栏「玻璃主题」的视觉参照与实现取材。所有链接已核验 HTTP 200（2026-09-11）。

**三层实现模型**（选型先看这个）：
1. Frosted —— `backdrop-filter: blur()` + 半透明填充 + 1px 亮边（最便宜，够做导航条）。
2. Tinted & layered —— 再加**顶部渐变高光 + inset 高光 + 柔和投影**（观感提升主要来自这层，几乎不加成本）。
3. Refractive —— SVG `feDisplacementMap`/`feTurbulence` 或 WebGL shader 做**折射变形**（真正「液态」，代价是两遍渲染）。

**官方与最佳范例**
- Apple 设计画廊（各 App 如何用 Liquid Glass）：https://developer.apple.com/cn/design/new-design-gallery/
- WWDC25 设计系统讲解（含 shape/同心圆规则）：https://wwdcindex.com/wwdc2025/356/
- Apple iOS 26 页（Liquid Glass 原始语境）：https://www.apple.com/os/ios/

**真实站点用法**
- New API（本工程既有参照，导航胶囊 = frosted + tinted）：https://www.newapi.ai
- The RLVNT Studios（Apple Liquid Glass 风格导航栏，orpetron 收录）：https://orpetron.com/blog/10-liquid-web-design-examples-defining-creativity-and-innovation/

**可直接看效果的在线演示**

**落地要点（性能与可读性）**
- `backdrop-filter` 是最贵的常用 CSS 属性；**blur ≤ 20px**（超过无感知差别），重叠玻璃层数越少越好；折射 = 额外一遍，只留 1 个 hero 元素。
- 半透明底必须有「地板」：底色不透明度建议 ≥ 0.6~0.7，正文不要放玻璃上，只用于导航/控件/单行标签。
- 降级：`@supports not (backdrop-filter: blur(1px))` → 实底；`prefers-reduced-transparency` / `prefers-reduced-motion` 各自分支。
